# Student Performance Dashboard

## Overview
This Power BI dashboard analyzes:
- Student performance
- Attendance
- Subject-wise marks
- Performance categories

## Tools Used
- Power BI
- Excel

## Features
- KPI Cards
- Scatter Chart
- Gauge Chart
- Donut Chart
- Treemap
- Interactive Slicers
